# صفحة مكتب الحسين

الملفات:
- index.html
- logo.jpg

للنشر على GitHub Pages:
1. أنشئ Repository جديد.
2. ارفع index.html و logo.jpg.
3. Settings → Pages.
4. اختر النشر من branch الرئيسي.
5. بعد النشر سيظهر رابط الموقع.

ملاحظة: الأزرار الوهمية (#) يمكن استبدالها بروابط صفحاتك أو ملفات الويب التي تملك حق توزيعها.
